# Leo Project Info

显示当前 Leo AI System 的项目信息。

## 功能

1. **技能统计**: 显示已安装的技能数量
2. **系统状态**: 显示各子系统状态
3. **快速操作**: 提供常用操作的快捷方式

## 使用方式

```bash
/leo-project-info
```

## 输出示例

```
=== Leo AI System ===

技能总数: 242+
核心模块: 6
子代理: 3
插件: 1

系统状态:
  - Hooks: ✅ 启用
  - MCP: ✅ 配置完成
  - 子代理: ✅ 已配置
  - 权限: ✅ 已定义
```

## 相关技能

- `brainstorming_skill` - 头脑风暴
- `writing_plans_skill` - 编写计划
- `executing_plans_skill` - 执行计划
