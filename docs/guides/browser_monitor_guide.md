## 💡 高效监控技巧

### 1. 使用多标签页

- 每个平台打开一个标签页
- 使用标签页组功能（Chrome/Edge 支持）
- 命名为"社交媒体监控"

### 2. 使用浏览器插件

**推荐插件**:
- **OneTab** - 合并标签页，节省内存
- **Workona** - 工作区管理
- ** Toby for Chrome** - 标签页管理

### 3. 固定标签页

- 右键标签页 → 固定
- 下次打开浏览器自动加载

### 4. 使用分屏功能

- Windows: `Win+←` / `Win+→`
- 同时查看多个平台

## ⚠️ 注意事项

### 1. 不要登录多个账号

- 可能触发风控
- 建议只用一个账号查看

### 2. 不要频繁刷新

- 每个账号间隔 5 分钟以上
- 避免被判定为机器人

### 3. 不要使用自动化工具

- 浏览器插件自动化
- Python 脚本自动化
- 可能触发反爬

### 4. 清理浏览器缓存

- 定期清理 Cookie
- 避免被追踪
