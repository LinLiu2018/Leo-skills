## ⚠️ 重要提示：风控风险说明

### 各平台风控等级

| 平台 | 风控等级 | 检测风险 | 封号风险 | 建议方案 |
|------|---------|---------|---------|---------|
| **X (Twitter)** | 🟢 低 | 低 | 低 | 官方 API |
| **公众号** | 🟡 中 | 中 | 中 | 第三方服务 |
| **视频号** | 🟡 中 | 中 | 中 | 第三方服务 |
| **抖音** | 🔴 高 | 高 | 高 | 第三方服务 |
| **小红书** | 🔴 高 | 高 | 高 | 第三方服务 |

### 会不会被检测到？

**答案**: **会，但风险可控**

#### 低风险方案（推荐）

1. **官方 API** - 最安全
   - 优点：官方允许，不会封号
   - 缺点：需要申请，有调用限制
   - 适用：X、公众号、视频号

2. **第三方服务** - 较安全
   - 优点：无需自己配置，服务商已处理好风控
   - 缺点：需要付费，数据有延迟
   - 适用：所有平台

3. **网页抓取** - 风险高
   - 优点：免费，数据实时
   - 缺点：容易触发反爬，可能封 IP
   - 适用：仅测试，不建议生产使用

## 📝 配置文件

### 位置

`src/leo_skills/tools/social_media_monitor_skill/config/accounts.json`

### 格式

```json
{
  "platform_name": [
    {
      "name": "账号名称",
      "id": "账号 ID",
      "category": "分类",
      "priority": "优先级"
    }
  ]
}
```

### 字段说明

| 字段 | 说明 | 必填 |
|------|------|------|
| name | 账号名称 | ✅ |
| id | 账号 ID（从平台获取） | ❌ |
| category | 分类（如"房产竞品"） | ❌ |
| priority | 优先级 (high/medium/low) | ❌ |

## ⚠️ 风控规避建议

### 1. 控制请求频率

| 平台 | 建议频率 | 说明 |
|------|---------|------|
| X | 100 次/小时 | 官方限制 |
| 公众号 | 1000 次/天 | 官方限制 |
| 抖音 | 50 次/小时 | 建议值 |
| 小红书 | 50 次/小时 | 建议值 |

### 2. 使用代理 IP

- 国内平台：使用国内代理
- 国外平台：使用海外代理
- 建议：使用住宅 IP 代理

### 3. 错峰监控

- 避免高峰期（20:00-22:00）
- 建议时间：凌晨 3:00-6:00

### 4. 使用官方 API

- 最安全，不会触发风控
- 但有调用限制
- 建议：优先使用官方 API

## ❓ 常见问题

### Q1: 没有 API Key 能用吗？

**答**: 可以，使用方案 C（仅监控公开数据），但有风控风险。

### Q2: 第三方服务贵吗？

**答**: 有免费套餐，付费套餐 500-2000 元/月。

### Q3: 会被封号吗？

**答**: 使用官方 API 或第三方服务不会封号。网页抓取有风险。

### Q4: 数据准确吗？

**答**: 官方 API 最准确，第三方服务有延迟，网页抓取最准确但有风险。

### Q5: 可以监控私人账号吗？

**答**: 不可以，仅能监控公开账号。
