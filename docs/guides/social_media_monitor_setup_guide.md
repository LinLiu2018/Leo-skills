## 三、平台接入方式

### 1. X (Twitter)

#### 方案 A: 官方 API (推荐)

**步骤**:
1. 申请 Twitter Developer Account
2. 创建 App 获取 API Key
3. 配置到系统

**成本**: 免费 - $100/月

#### 方案 B: 第三方服务

**推荐服务**:
- Social Blade
- Brandwatch
- Talkwalker

**成本**: $50-500/月

---

### 2. 微信公众号

#### 方案 A: 微信开放平台

**步骤**:
1. 注册微信开放平台账号
2. 创建应用获取 AppID/AppSecret
3. 授权公众号
4. 调用 API 获取内容

**成本**: 免费

**限制**: 需要公众号管理员授权

#### 方案 B: 第三方服务

**推荐服务**:
- 新榜
- 清博大数据
- 西瓜数据

**成本**: 免费 - 500 元/月

## 四、快速开始

### Step 1: 复制配置模板

```bash
cd src/leo_skills/tools/social_media_monitor_skill/config
cp accounts.json.example accounts.json
```

### Step 2: 编辑账号配置

编辑 `accounts.json`，添加您要监控的账号。

### Step 3: 配置 API

根据选择的平台接入方式，配置相应的 API Key。

### Step 4: 测试监控

```bash
# 手动执行监控
python scripts/cron/social_media_monitor.py --manual
```

### Step 5: 查看报告

报告保存在：`reports/social_media_monitor/`

## 八、常见问题

### Q1: 为什么有些平台无法获取数据？

**答**: 需要相应平台的 API 授权或第三方服务账号。

### Q2: 监控频率是多少？

**答**: 默认每天 9 点执行一次，可手动调整。

### Q3: 可以监控竞品账号吗？

**答**: 可以，但需要是公开账号。

### Q4: 报告保存在哪里？

**答**: `reports/social_media_monitor/` 目录。
