# OpenClaw 语音对话配置指南

**创建时间**: 2026-02-27  
**目标**: 实现双向语音对话 (STT + TTS)

---

## 一、当前语音能力

### ✅ 已支持

**TTS (文字转语音)**:
- 可以将回复转换为语音
- 通过飞书播放音频
- 使用系统 TTS 服务

### ❌ 待配置

**STT (语音转文字)**:
- 需要配置语音识别服务
- 支持飞书语音消息输入
- 或使用 Whisper 本地识别

---

## 二、配置方案

### 方案 1: 飞书原生语音 (推荐) ⭐⭐⭐⭐⭐

**优点**:
- 无需额外配置
- 飞书 App 直接支持
- 语音自动转文字

**配置步骤**:
1. 打开飞书 App
2. 进入与机器人的对话框
3. 点击输入框旁的麦克风图标
4. 说话 → 自动转文字 → 发送

**适用场景**: 移动端快速交互

---

### 方案 2: Whisper 本地识别 ⭐⭐⭐⭐

**优点**:
- 本地运行，隐私保护
- 支持多种语言
- 高准确率

**配置步骤**:

```bash
# 1. 安装 Whisper
pip install openai-whisper

# 2. 下载模型
whisper download --model base

# 3. 配置 OpenClaw
# 编辑 ~/.openclaw/openclaw.json
{
  "voice": {
    "stt": {
      "provider": "whisper",
      "model": "base",
      "language": "zh"
    },
    "tts": {
      "provider": "edge",
      "voice": "zh-CN-XiaoxiaoNeural"
    }
  }
}
```

**适用场景**: 桌面端、隐私敏感场景

---

### 方案 3: 云端 STT 服务 ⭐⭐⭐

**服务商**:
- Azure Speech Service
- Google Cloud Speech-to-Text
- 阿里云语音识别

**配置示例** (Azure):

```json
{
  "voice": {
    "stt": {
      "provider": "azure",
      "api_key": "YOUR_AZURE_KEY",
      "region": "eastasia",
      "language": "zh-CN"
    }
  }
}
```

**成本**: 约 $0.01/分钟

## 四、快速启用

### 立即启用 (飞书原生)

1. **打开飞书 App**
2. **进入对话框**
3. **点击麦克风图标** 🎤
4. **说话** → 自动转文字
5. **发送** → 我看到文字回复

### 高级配置 (Whisper)

```bash
# 安装依赖
pip install openai-whisper edge-tts

# 测试 STT
whisper audio.mp3 --model base --language zh

# 测试 TTS
edge-tts --text "你好" --voice zh-CN-XiaoxiaoNeural --output test.mp3
```

## 七、故障排查

### 问题 1: 语音无法转文字

**原因**: 飞书权限问题

**解决**:
- 检查飞书麦克风权限
- 重启飞书 App
- 更新飞书到最新版

### 问题 2: TTS 无法播放

**原因**: 音频格式问题

**解决**:
- 检查飞书是否支持 MP3
- 尝试 WAV 格式
- 重启 Gateway

### 问题 3: 识别准确率低

**原因**: 环境噪音或口音

**解决**:
- 安静环境录音
- 清晰发音
- 使用更高级的 Whisper 模型 (large)

## 八、最佳实践

### 语音交互建议

1. **简短指令**: 每次说一个明确指令
2. **避免长句**: 分段说，更准确
3. **确认理解**: 重要操作让我复述确认
4. **环境安静**: 减少背景噪音

### 效率技巧

1. **语音 + 文字混合**: 快速操作用语音，复杂内容用文字
2. **TTS 播报报告**: 长报告用语音，边听边做其他事
3. **语音命令快捷**: 常用操作设置语音命令
