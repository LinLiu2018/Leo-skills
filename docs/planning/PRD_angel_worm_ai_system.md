# 天使虫AI操盘手系统 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品定位
**全链路AI数字员工操作系统** - 通过AI技术替代90%的人工重复劳动，实现24小时无人化运营。

### 1.2 目标用户
- 电商运营团队
- 私域流量主
- MCN机构
- 个人IP创业者

### 1.3 核心价值主张
- **降本增效**: 1个AI系统 = 10人运营团队
- **全平台覆盖**: 抖音/快手/视频号/小红书/微信统一管理
- **智能化运营**: AI自动生成内容、自动发布、自动获客

## 2. 功能需求

### 2.1 界面布局 (新榜矩阵通风格)

#### 整体布局
```
┌─────────────────────────────────────────────────────────────┐
│  Logo      全局搜索                    通知  设置  用户头像  │  ← 顶部导航栏 (56px)
├──────────┬──────────────────────────────────────────────────┤
│          │                                                  │
│  导航    │              主工作区                            │
│  菜单    │         (动态内容，根据路由变化)                  │
│  (200px) │                                                  │
│          │                                                  │
│          ├──────────────────────────────────────────────────┤
│          │              执行命令面板                         │
│          │         (可折叠，显示日志/状态)                  │
├──────────┴──────────────────────────────────────────────────┤
│                     状态栏                                  │  ← 底部状态栏 (24px)
└─────────────────────────────────────────────────────────────┘
```

#### 导航结构
1. **Dashboard** - 数据总览
2. **账号矩阵** - 多平台账号管理
3. **内容创作** - AI视频/文案生成
4. **智能发布** - 定时发布/矩阵分发
5. **自动化运营** - 养号/截流/获客
6. **私域管理** - 微信/朋友圈运营
7. **AI指令台** - 自然语言控制中心
8. **数据分析** - 运营数据报表
9. **系统设置** - 配置/日志/插件

### 2.2 核心功能模块

#### 模块1: Dashboard数据看板
- **账号概览**: 总账号数、在线数、异常数
- **内容统计**: 今日发布、播放量、互动量
- **获客数据**: 新增线索、转化率、私域增长
- **实时动态**: 最近操作日志流
- **快捷入口**: 常用功能一键直达

#### 模块2: 账号矩阵管理
- **平台分类**: 抖音/快手/视频号/小红书/微信
- **账号列表**: 头像、昵称、粉丝数、状态
- **分组管理**: 支持自定义分组
- **批量操作**: 导入/导出/批量登录
- **状态监控**: 在线状态、风控预警

#### 模块3: AI内容创作
- **视频生成**:
  - 文生视频 (T2V) - 调用Sora 2 API
  - 图生视频 (I2V)
  - 数字人口播 - 本地HeyGem部署
  - 智能混剪 - 素材自动组合
- **文案生成**:
  - 爆款标题生成
  - 视频脚本生成
  - 评论区话术生成
- **素材库**:
  - 本地素材管理
  - AI素材生成历史
  - 云端素材同步

#### 模块4: 智能发布系统
- **内容排期**: 日历视图管理发布计划
- **矩阵分发**: 一稿多发，平台适配
- **定时发布**: 支持预设发布时间
- **发布监控**: 实时显示发布状态
- **失败重试**: 自动重试机制

#### 模块5: 自动化运营
- **智能养号**:
  - 模拟真人浏览行为
  - 随机停留(3-8秒)
  - 随机点赞/关注
  - 防检测轨迹模拟
- **评论区截流**:
  - 关键词监控("怎么买"、"加微信"等)
  - 自动回复引导
  - 私信话术发送
- **AI客服**:
  - 自动读取私信
  - 基于知识库回复
  - 引导留资

#### 模块6: 私域流量管理
- **微信自动化**:
  - 自动通过好友申请
  - 验证语自动回复
  - 欢迎语自动发送
- **朋友圈运营**:
  - 定时发布朋友圈
  - 自动点赞好友动态
  - AI生成评论互动

#### 模块7: AI指令控制台
- **自然语言输入**: 支持语音/文本指令
- **任务拆解可视化**: 显示AI思考过程
- **一键执行**: 确认后自动执行全流程
- **示例指令**:
  - "帮我做一个关于咖啡的视频，发到抖音"
  - "监控竞品账号最近10条视频数据"
  - "把评论区要买的人都加到微信"

## 3. 技术架构

### 3.1 系统架构
```
┌─────────────────────────────────────────────────────────────┐
│                      前端层 (Electron)                       │
│                   React + TypeScript + AntD                 │
└──────────────────────┬──────────────────────────────────────┘
                       │ IPC / HTTP
┌──────────────────────▼──────────────────────────────────────┐
│                      后端层 (Python)                         │
│                    FastAPI + SQLAlchemy                     │
└──────────────────────┬──────────────────────────────────────┘
                       │
       ┌───────────────┼───────────────┐
       ▼               ▼               ▼
┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│   MySQL     │ │  ChromaDB   │ │  Redis      │
│  (业务数据)  │ │  (向量库)    │ │  (缓存队列)  │
└─────────────┘ └─────────────┘ └─────────────┘
                       │
       ┌───────────────┼───────────────┐
       ▼               ▼               ▼
┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│  视频生成API │ │  大模型API   │ │  平台接口   │
│  Sora/可灵  │ │ DeepSeek等  │ │ 抖音/微信等 │
└─────────────┘ └─────────────┘ └─────────────┘
```

### 3.2 技术选型
| 组件 | 选型 | 理由 |
|------|------|------|
| 前端框架 | Electron 28+ | 跨平台桌面应用 |
| UI库 | Ant Design 5.x | 专业企业级组件 |
| 图表 | AntV / ECharts | 数据可视化 |
| 后端框架 | FastAPI | 高性能异步API |
| ORM | SQLAlchemy 2.0 | 成熟稳定 |
| 任务队列 | Celery + Redis | 异步任务处理 |
| 数据库 | MySQL 8.0 | 主业务数据库 |
| 向量库 | ChromaDB | 本地向量存储 |

## 4. 非功能性需求

### 4.1 性能要求
- 首屏加载 < 3秒
- 界面切换 < 500ms
- 视频生成响应 < 30秒
- 支持10+账号并发操作

### 4.2 安全与风控
- 设备指纹隔离
- IP代理池轮换
- 操作行为随机化
- 敏感操作二次确认

### 4.3 可扩展性
- 插件化架构
- 模块化设计
- 支持新平台接入

## 5. 界面原型要点

### 5.1 视觉风格
- **主色调**: #1677FF (Ant Design蓝)
- **辅助色**: #52C41A (成功)、#FAAD14 (警告)、#F5222D (错误)
- **背景色**: #F0F2F5 (浅灰)
- **文字色**: #262626 (主文)、#595959 (次要)
- **圆角**: 8px (卡片)、4px (按钮)
- **阴影**: 0 2px 8px rgba(0,0,0,0.08)

### 5.2 组件规范
- 按钮: 主按钮(实心)、次按钮(描边)、文字按钮
- 卡片: 带hover上浮效果
- 表格: 支持排序、筛选、分页
- 表单: 统一标签右对齐
- 弹窗: 确认/取消按钮位置统一
