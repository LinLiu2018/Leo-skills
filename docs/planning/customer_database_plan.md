# 客户 Bitable 数据库实现计划

**创建时间**: 2026-02-26  
**优先级**: P0 (核心业务)  
**预计工时**: 0.5 天

---

## 一、数据库定位

与口袋助理 CRM 互补，专注 AI 分析所需数据结构。

**口袋助理 CRM**: 客户基本信息、跟进记录、合同管理  
**Bitable 数据库**: 客户画像标签、AI 分析结果、推荐方案

---

## 二、表结构设计

### 表 1：客户画像表

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 客户 ID | 文本 | 唯一标识（与口袋助理关联） |
| 客户姓名 | 文本 | - |
| 联系方式 | 电话 | - |
| 客户类型 | 单选 | 别墅/住宅/商业/租赁 |
| 需求类型 | 单选 | 刚需/改善/投资/养老 |
| 预算范围 | 文本 | 如"500-800 万" |
| 区域偏好 | 多选 | 鄞州/海曙/江北/镇海/北仑 |
| 户型偏好 | 文本 | 如"4 房 2 厅" |
| 面积偏好 | 文本 | 如"150-200㎡" |
| 购房动机 | 文本 | 如"度假养老"、"学区" |
| 客户等级 | 单选 | A(高意向)/B(中意向)/C(低意向) |
| 来源渠道 | 单选 | 小红书/抖音/朋友圈/转介绍 |
| AI 标签 | 文本 | AI 分析生成的标签 |
| 推荐房源 | 文本 | AI 推荐的房源 ID |
| 跟进状态 | 单选 | 未联系/跟进中/带看/谈判/成交 |
| 备注 | 文本 | - |
| 创建时间 | 日期 | - |
| 更新时间 | 日期 | - |

### 表 2：跟进记录表

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 记录 ID | 文本 | 唯一标识 |
| 客户 ID | 文本 | 关联客户 |
| 跟进时间 | 日期时间 | - |
| 跟进方式 | 单选 | 电话/微信/面谈/带看 |
| 跟进内容 | 长文本 | 详细记录 |
| 客户反馈 | 长文本 | 客户意见/顾虑 |
| AI 话术建议 | 长文本 | AI 生成的下一步话术 |
| 下次跟进 | 日期 | 提醒时间 |
| 跟进人 | 文本 | - |

### 表 3：房源匹配表

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 匹配 ID | 文本 | 唯一标识 |
| 客户 ID | 文本 | 关联客户 |
| 房源 ID | 文本 | 关联房源 |
| 匹配度 | 数字 | 0-100 分 |
| 匹配理由 | 长文本 | AI 分析结果 |
| 推荐时间 | 日期 | - |
| 客户反馈 | 单选 | 感兴趣/不考虑/已带看 |
| 状态 | 单选 | 待推荐/已推荐/已带看/已成交 |

## 三、与口袋助理对接

### 方案 A：手动导入导出（快速启动）
- 从口袋助理导出客户 Excel
- 上传到 Bitable
- AI 处理后手动回填

### 方案 B：飞书集成（推荐）
- 口袋助理如有飞书集成，自动同步

### 方案 C：API 对接（长期）
- 调用口袋助理 API
