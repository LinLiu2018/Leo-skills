- 住宅成交价/租金监控
- 新盘开盘信息收集

### 2. 内容创作（运营模块 - 赚钱）
- 住宅房源文案
- 购房指南内容
- 租金投资分析

### 3. 客户跟进（运营模块 - 赚钱）
- 首套/改善客户画像
- 购房资格评估
- 贷款方案建议

### 4. 数据复盘（学习模块 - 进化）
- 住宅成交数据分析
- 客户来源渠道分析
- 话术转化率优化
