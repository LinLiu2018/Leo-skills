# Villa Agent - 别墅事业部代理实现计划

**创建时间**: 2026-02-26  
**优先级**: P0 (核心业务)  
**预计工时**: 1 天

---

## 一、Agent 定位

**角色**: 宁波度假别墅专家  
**职责**: 别墅房源管理、别墅客户跟进、别墅内容创作  
**绑定模型**: qwen3.5-plus  
**触发词**: 别墅、度假别墅、养老别墅、宁波别墅

---

## 二、核心能力

### 1. 市场情报（运营模块 - 赚钱）
- 每日小红书/抖音别墅内容监控
- 宁波别墅新盘/价格动态追踪
- 竞品别墅项目分析

### 2. 内容创作（运营模块 - 赚钱）
- 别墅卖点提炼
- 短视频脚本生成
- 朋友圈/公众号文案

### 3. 客户跟进（运营模块 - 赚钱）
- 别墅客户画像分析
- 跟进话术建议
- 带看后跟进提醒

### 4. 数据复盘（学习模块 - 进化）
- 每周别墅内容效果分析
- 客户转化漏斗分析
- 话术迭代优化
