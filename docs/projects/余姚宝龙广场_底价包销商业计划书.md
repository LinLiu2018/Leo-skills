## 三、底价包销模式说明

### 3.1 什么是底价包销

**底价包销**是指代理商与开发商签订协议，以**低于市场价格的底价**包下一定数量的房源，代理商在约定期限内自主定价销售，赚取差价利润的商业模式。

### 3.2 运作流程

```
开发商 ──(底价)──► 代理商 ──(市场价)──► 购房者
     │                    │
     │    包销协议        │    销售差价
     │◄──────────────────┘
     │      结算
```

### 3.3 核心优势

| 角色 | 优势 |
|------|------|
| **开发商** | 快速回笼资金、转移去化压力、锁定最低售价 |
| **代理商** | 获取超额利润、掌控定价权、规模化运作 |
| **购房者** | 获得专业服务、更多选择、促销优惠 |

## 六、风险分析

### 6.1 主要风险

| 风险类型 | 风险描述 | 应对措施 |
|----------|----------|----------|
| **市场风险** | 市场行情下行，销售价格低于包销底价 | 设置保底条款、止损机制 |
| **去化风险** | 销售周期内无法完成去化目标 | 延期销售、降价促销 |
| **政策风险** | 房地产调控政策收紧 | 关注政策动向、及时调整 |
| **资金风险** | 货款支付压力、资金周转困难 | 分期付款、多渠道融资 |
| **竞品风险** | 周边项目低价竞争 | 产品差异化、渠道创新 |

### 6.2 风险控制建议

1. **设置止损线**：若连续3个月去化率低于预期，启动降价促销
2. **保证金制度**：向开发商缴纳10%保证金，完成80%去化后返还
3. **价格保护**：合同明确最低售价保障，避免开发商自行降价
4. **退出条款**：约定6个月后未完成去化的处理方式
