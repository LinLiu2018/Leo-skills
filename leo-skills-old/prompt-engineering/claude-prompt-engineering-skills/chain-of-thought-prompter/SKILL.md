# Chain of Thought Prompter - 思维链提示器

## 功能描述

这个技能帮助你使用思维链 (Chain of Thought, CoT) 技术,引导 AI 进行逐步推理,特别适合需要复杂分析、多步骤推理或创意问题解决的任务。

## 什么是思维链?

思维链是一种提示技术,要求 AI 在给出最终答案前,先展示其推理过程。这能显著提高复杂任务的准确性和可靠性。

## 何时使用思维链?

✅ **适合使用的场景**:

- 数学问题和逻辑推理
- 多步骤分析任务
- 需要权衡多个因素的决策
- 创意问题解决
- 复杂的文本理解和推理
- 需要透明推理过程的任务

❌ **不适合的场景**:

- 简单的事实查询
- 直接的信息提取
- 格式转换任务
- 已经很明确的简单任务

## 三种实现方式

### 1. 基础思维链 (Basic CoT)

最简单的方式,只需添加一句话:

```
[你的任务描述]

在回答之前,请逐步思考。
```

**示例**:

```
计算以下问题的答案:
一个商店打 7 折,原价 150 元的商品,买两件后再用 20 元优惠券,最终需要支付多少钱?

在回答之前,请逐步思考。
```

### 2. 引导式思维链 (Guided CoT)

提供具体的推理步骤指导:

```
[你的任务描述]

在完成任务之前,请按以下步骤思考:
1. [步骤 1]
2. [步骤 2]
3. [步骤 3]

然后基于你的分析完成任务。
```

**示例**:

```
为这位捐赠者撰写个性化的募捐邮件。

捐赠者信息: {{DONOR_INFO}}
项目信息: {{PROGRAM_INFO}}

在撰写邮件之前,请按以下步骤思考:
1. 首先,分析这位捐赠者的捐赠历史,思考什么样的信息可能吸引他们
2. 然后,考虑项目的哪些方面会与捐赠者产生共鸣
3. 最后,基于你的分析撰写个性化的募捐邮件
```

### 3. 结构化思维链 (Structured CoT)

使用 XML 标签分隔思考过程和最终输出:

```
[你的任务描述]

请在 <thinking> 标签中展示你的思考过程,然后在 <answer> 标签中提供最终答案。

<thinking>
[你的推理过程]
</thinking>

<answer>
[最终答案]
</answer>
```

**示例**:

```
分析这个商业计划的可行性。

商业计划: {{BUSINESS_PLAN}}

请在 <thinking> 标签中展示你的分析过程,然后在 <recommendation> 标签中提供最终建议。

分析时考虑:
- 市场需求
- 竞争态势
- 财务可行性
- 执行风险
```

## 使用模板

### 模板 1: 问题解决

```
<problem>
{{PROBLEM_DESCRIPTION}}
</problem>

<instructions>
解决上述问题。在 <thinking> 标签中展示你的推理过程:

1. 理解问题: 问题的核心是什么?
2. 识别已知和未知: 我们知道什么?需要找出什么?
3. 制定策略: 可以使用什么方法?
4. 执行计划: 逐步解决
5. 验证答案: 答案是否合理?

然后在 <solution> 标签中提供清晰的解决方案。
</instructions>
```

### 模板 2: 决策分析

```
<scenario>
{{DECISION_SCENARIO}}
</scenario>

<options>
选项 A: {{OPTION_A}}
选项 B: {{OPTION_B}}
选项 C: {{OPTION_C}}
</options>

<analysis_framework>
在 <thinking> 标签中进行分析:

1. 识别决策标准: 什么因素最重要?
2. 评估每个选项:
   - 选项 A 的优缺点
   - 选项 B 的优缺点
   - 选项 C 的优缺点
3. 权衡取舍: 如何平衡不同因素?
4. 考虑风险: 每个选项的潜在风险是什么?
5. 得出结论: 基于分析,哪个选项最优?

然后在 <recommendation> 标签中提供明确的建议和理由。
</analysis_framework>
```

### 模板 3: 创意任务

```
<creative_brief>
{{TASK_DESCRIPTION}}
</creative_brief>

<thinking_process>
在开始创作之前,在 <brainstorm> 标签中进行头脑风暴:

1. 理解目标: 这个任务的核心目标是什么?
2. 受众分析: 目标受众是谁?他们的需求是什么?
3. 创意方向: 可以探索哪些创意角度?
4. 评估想法: 哪些想法最有潜力?
5. 细化概念: 如何将最佳想法发展成完整方案?

然后在 <final_output> 标签中呈现最终创意作品。
</thinking_process>
```

### 模板 4: 文本分析

```
<text>
{{TEXT_TO_ANALYZE}}
</text>

<analysis_task>
分析上述文本的 {{ANALYSIS_ASPECT}}。

在 <thinking> 标签中展示你的分析过程:

1. 初步印象: 文本的整体特点是什么?
2. 关键元素识别: 有哪些重要的细节?
3. 模式和主题: 能识别出什么模式或主题?
4. 深层含义: 有什么隐含的意义或暗示?
5. 综合判断: 基于以上分析,得出什么结论?

然后在 <analysis_result> 标签中提供结构化的分析结果。
</analysis_task>
```

## 高级技巧

### 1. 多层次思维链

对于特别复杂的任务,使用多层次思维:

```
<task>
{{COMPLEX_TASK}}
</task>

<thinking_levels>
第一层思考 - 宏观分析:
<macro_thinking>
[整体理解和框架构建]
</macro_thinking>

第二层思考 - 细节分析:
<detail_thinking>
[具体问题的深入分析]
</detail_thinking>

第三层思考 - 综合判断:
<synthesis_thinking>
[整合所有分析,形成结论]
</synthesis_thinking>
</thinking_levels>

<final_answer>
[最终答案]
</final_answer>
```

### 2. 自我批评思维链

让 AI 在推理过程中自我批评:

```
在 <thinking> 标签中思考,并在每个步骤后进行自我批评:

步骤 1: [初步想法]
自我批评: 这个想法有什么问题?有没有遗漏?

步骤 2: [改进的想法]
自我批评: 现在的方向对吗?还能如何改进?

步骤 3: [最终推理]
自我批评: 这个结论可靠吗?有充分的证据支持吗?
```

### 3. 对比式思维链

让 AI 考虑多个角度:

```
<thinking>
正方观点:
[支持某个结论的推理]

反方观点:
[反对该结论的推理]

权衡分析:
[比较两方观点的强弱]

最终判断:
[基于权衡得出的结论]
</thinking>
```

## 与扩展思维 (Extended Thinking) 的关系

### Claude 的扩展思维功能

Claude 提供了扩展思维功能,可以自动进行结构化推理。当扩展思维可用时:

- **优先使用扩展思维**: 对于复杂推理任务
- **手动 CoT 仍有价值**: 当你需要透明、可审查的推理过程时
- **两者可以结合**: 扩展思维 + 手动 CoT 可以互补

### 何时使用手动 CoT 而非扩展思维?

1. 扩展思维不可用(如免费版 Claude.ai)
2. 需要审查和验证推理过程
3. 需要特定的推理结构
4. 想要控制推理的方向和深度

## 实际应用示例

### 示例 1: 数学问题

```
问题: 一个水池有两个进水管和一个出水管。甲管单独注满需要 6 小时,乙管单独注满需要 8 小时,丙管单独排空需要 12 小时。如果三管同时开放,多久能注满水池?

请在 <thinking> 标签中逐步推理:

<thinking>
1. 理解问题:
   - 甲管效率: 1/6 池/小时
   - 乙管效率: 1/8 池/小时
   - 丙管效率: -1/12 池/小时(排水)
   
2. 计算合并效率:
   - 总效率 = 1/6 + 1/8 - 1/12
   - 找公分母 24: 4/24 + 3/24 - 2/24 = 5/24 池/小时
   
3. 计算时间:
   - 时间 = 1 池 ÷ (5/24 池/小时) = 24/5 = 4.8 小时
   
4. 验证:
   - 4.8 小时内,甲管注入: 4.8 × 1/6 = 0.8 池
   - 4.8 小时内,乙管注入: 4.8 × 1/8 = 0.6 池
   - 4.8 小时内,丙管排出: 4.8 × 1/12 = 0.4 池
   - 净注入: 0.8 + 0.6 - 0.4 = 1 池 ✓
</thinking>

<answer>
三管同时开放,需要 4.8 小时(即 4 小时 48 分钟)能注满水池。
</answer>
```

### 示例 2: 商业分析

```
<scenario>
一家初创公司正在考虑是否进入共享电动滑板车市场。
市场数据: {{MARKET_DATA}}
公司资源: {{COMPANY_RESOURCES}}
竞争对手: {{COMPETITORS}}
</scenario>

<analysis>
在 <thinking> 标签中进行 SWOT 分析和可行性评估:

<thinking>
1. 市场机会分析:
   - 市场规模: [分析市场数据]
   - 增长趋势: [识别趋势]
   - 用户需求: [评估需求强度]
   
2. 竞争态势:
   - 主要竞争对手: [列出并分析]
   - 市场集中度: [评估竞争激烈程度]
   - 差异化机会: [识别可能的差异化点]
   
3. 公司能力评估:
   - 资金充足性: [评估资金是否足够]
   - 技术能力: [评估技术实力]
   - 团队经验: [评估团队背景]
   
4. 风险评估:
   - 监管风险: [考虑政策风险]
   - 运营风险: [考虑执行难度]
   - 财务风险: [考虑资金风险]
   
5. 综合判断:
   - 优势和劣势权衡
   - 机会和威胁平衡
   - 最终建议
</thinking>

<recommendation>
[基于分析的明确建议]
</recommendation>
</analysis>
```

## 注意事项

1. **不要过度使用**: 简单任务不需要思维链
2. **保持聚焦**: 思维过程应该与任务相关
3. **结构清晰**: 使用标签或编号使推理过程易于跟踪
4. **验证结论**: 在思维链中包含自我验证步骤
