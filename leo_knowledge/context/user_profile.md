        "msg_type": "text",
        "content": json.dumps({"text": content})
    }).encode('utf-8')
    req = urllib.request.Request(url, data=data, headers={
        'Content-Type': 'application/json',
        'Authorization': f'Bearer {token}'
    })
    with urllib.request.urlopen(req, timeout=30) as response:

## 8. 命名规范标准化：全局唯一规范
- **统一使用下划线 (underscore)，禁止使用连字符 (hyphen)**
- 此规范适用于：项目根目录、所有子目录、Python 文件、配置文件
- **Skills**：格式为 `{功能}_{类型}_skill`
- **Agents**：格式为 `{领域}_agent`
- **Workflows**：格式为 `{业务}_pipeline`
- **禁止命名**：
  - Python 缓存目录 `__pycache__` (自动生成，除外)
  - Git hooks 目录 (Git 规范)
  - 第三方插件目录 (`.claude-plugin`, `.leo-skills` 等)
  - 配置文件中的 category 必须使用 snake_case（如 content_creation 而非 content-creation）

- **自动化检查**：新增技能/代理/工作流时，自动按规范命名并更新配置
- **自动化规则**：所有新创建的 Skill/Agent/Workflow 必须符合 snake_case 命名

- **正确示例**：
  - `leo_ai_system/` (项目根目录)
  - `leo_system.py` (主文件)
  - `leo_skills/` (技能目录)
  - `web_search_skill/` (技能目录)

## 10. 命名规范与去重机制

> **强制执行**: 符合 [system_architecture.md](src/leo_knowledge/context/system_architecture.md#7-去重与规范化机制-deduplication--standardization) 定义的标准

### 10.1 命名规范（强制）

| 类型 | 格式 | 示例 |
|-----|------|------|
| 技能目录 | `{功能}_{类型}_skill` | `web_search_skill` |
| 代理目录 | `{领域}_agent` | `research_agent` |
| 工作流目录 | `{业务}_pipeline` | `content_pipeline` |
| Python类 | `PascalCase` | `ResearchAgent` |
| Python函数/变量 | `snake_case` | `execute_task` |

**禁止使用**:
- `-` 连字符
- 空格
- 大写字母开头的目录/文件名
- 中文目录名

### 10.2 强制去重机制

**新增前检查**:
- [ ] 功能重复检查（搜索 skill_index）
- [ ] 命名冲突检查
- [ ] 能力重叠评估

**重复处理**:
- 功能完全相同 → 合并为最优实现
- 功能部分重叠 → 整合能力
- 功能相似但不同 → 保留并明确区分

### 10.3 目录规范化状态

| 状态 | 原名称 | 新名称 |
|---------|------|---------|
| ✅ 已完成 | `剪口播` | `cut_speech_skill` |
| ✅ 已完成 | `剪辑` | `video_editing_skill` |
| ✅ 已完成 | `字幕` | `subtitle_skill` |
| ✅ 已完成 | `安装` | `install_skill` |
| ✅ 已完成 | `自更新` | `auto_update_skill` |
