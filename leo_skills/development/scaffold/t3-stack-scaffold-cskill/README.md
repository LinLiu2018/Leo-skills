# T3 Stack Scaffold

快速创建 T3 Stack 全栈项目

## 快速开始

```bash
# 创建标准项目
python scripts/main.py --name my-app

# 完整配置
python scripts/main.py --name my-app --trpc --prisma --next-auth --tailwind

# 查看所有选项
python scripts/main.py --options
```

## 技术栈

- Next.js 14 (App Router)
- TypeScript
- tRPC
- Prisma / Drizzle
- NextAuth.js
- Tailwind CSS
