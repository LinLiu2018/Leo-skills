# Research Pipeline

## 状态
🚧 规划中

## 用途
研究调研工作流，用于定义和执行研究调研相关的工作流程。

## 规划功能
- [ ] 信息搜集工作流
- [ ] 资料整理工作流
- [ ] 深度分析工作流
- [ ] 研究报告生成工作流

## 工作流示例
```yaml
name: research-pipeline
steps:
  - search: 信息搜集
  - organize: 资料整理
  - analyze: 深度分析
  - report: 生成报告
```

## 集成技能
- research-assistant-cskill: 研究助手
- web-search-cskill: 网页搜索
- obsidian-sync-cskill: Obsidian 同步
