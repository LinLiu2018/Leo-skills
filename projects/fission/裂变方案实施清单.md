## 📅 第4-5天：服务器部署

### ✅ 任务清单

- [ ] 连接服务器
- [ ] 安装环境（Python, Nginx, Supervisor）
- [ ] 上传代码
- [ ] 配置Nginx
- [ ] 配置进程守护
- [ ] 测试访问

### 📝 操作指南

**连接服务器**:

```bash
# Windows用户使用Xshell或PuTTY
# Mac/Linux用户使用终端
ssh root@your_server_ip
```

**一键安装环境**:

```bash
# 复制以下命令，一次性执行
apt update && apt upgrade -y && \
apt install python3 python3-pip nginx supervisor git -y && \
echo "环境安装完成！"
```

**上传代码**:

```bash
# 方法1: 使用FTP工具（FileZilla）上传到 /var/www/fission

# 方法2: 使用Git
cd /var/www
git clone your_git_repo fission
cd fission

# 方法3: 手动创建文件
mkdir -p /var/www/fission
cd /var/www/fission
# 然后逐个创建文件并粘贴代码
```

**安装Python依赖**:

```bash
cd /var/www/fission
pip3 install Flask==2.3.0 Flask-CORS==4.0.0
```

**配置Nginx**:

```bash
# 创建配置文件
cat > /etc/nginx/sites-available/fission << 'EOF'
server {
    listen 80;
    server_name your_domain.com www.your_domain.com;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
EOF

# 启用配置
ln -s /etc/nginx/sites-available/fission /etc/nginx/sites-enabled/
rm /etc/nginx/sites-enabled/default  # 删除默认配置
nginx -t  # 测试配置
systemctl restart nginx
```

**配置进程守护**:

```bash
# 创建Supervisor配置
cat > /etc/supervisor/conf.d/fission.conf << 'EOF'
[program:fission]
directory=/var/www/fission
command=python3 app.py
autostart=true
autorestart=true
stderr_logfile=/var/log/fission.err.log
stdout_logfile=/var/log/fission.out.log
user=root
EOF

# 启动应用
supervisorctl reread
supervisorctl update
supervisorctl start fission
supervisorctl status  # 查看状态
```

**测试访问**:

```bash
# 浏览器访问
http://your_domain.com

# 或者先用IP测试
http://your_server_ip
```

## 🚨 常见问题处理

### 问题1: 网站无法访问

```bash
# 检查Nginx状态
systemctl status nginx

# 检查应用状态
supervisorctl status fission

# 查看错误日志
tail -f /var/log/fission.err.log

# 重启服务
supervisorctl restart fission
systemctl restart nginx
```

### 问题2: 数据库错误

```bash
# 检查数据库文件
ls -lh /var/www/fission/fission.db

# 检查权限
chmod 666 /var/www/fission/fission.db

# 重新初始化（慎用，会清空数据）
rm /var/www/fission/fission.db
supervisorctl restart fission
```

### 问题3: 分享链接无效

```bash
# 检查用户ID是否正确
sqlite3 /var/www/fission/fission.db "SELECT id, name, phone FROM users WHERE id = 1;"

# 检查邀请关系
sqlite3 /var/www/fission/fission.db "SELECT * FROM invites WHERE inviter_id = 1;"
```
