## 三、配置步骤

### Step 1: 注册各平台账号

1. 阿里云百炼：bailian.console.aliyun.com
2. 智谱 AI：open.bigmodel.cn
3. DeepSeek：platform.deepseek.com
4. MiniMax：platform.minimaxi.com
5. Kimi：platform.moonshot.cn

### Step 2: 获取 API Key

在各平台控制台获取 API Key，保存到配置文件。

### Step 3: 修改 OpenClaw 配置

编辑 `~/.openclaw/openclaw.json`，添加模型配置。

### Step 4: 重启 Gateway

```bash
cd D:\openclaw
node openclaw.mjs gateway restart
```

### Step 5: 验证配置

```bash
openclaw agent --message "测试"
```

## 六、常见问题

### Q1: 哪个模型性价比最高？

**答**: GLM-4-Flash (¥0.0001/K) 最便宜，Qwen3.5-Plus (¥0.004/K) 性价比最高。

### Q2: 免费额度够用吗？

**答**: 日常使用完全够用，2500 万 + Token 免费额度。

### Q3: 如何切换模型？

**答**: 修改 `openclaw.json` 中的 `model.primary` 配置。

### Q4: 多个模型如何负载均衡？

**答**: 在 `models` 配置中列出多个模型，OpenClaw 会自动负载均衡。
