# 宁波法拍房团队招聘计划

**编制日期**: 2026-02-27  
**阶段**: 阶段 1 (代拍 + 助贷服务)  
**团队规模**: 5-8 人

---

## 一、组织架构

```
创始人/CEO
├── 业务部 (2 人)
│   ├── 业务经理 A
│   └── 业务经理 B
├── 法拍部 (2 人)
│   ├── 法拍专员 A
│   └── 法拍专员 B
├── 法务部 (1 人 + 兼职)
│   ├── 法务顾问
│   └── 兼职律师
└── 行政财务部 (1 人)
    └── 财务/行政
```

## 二、岗位详细说明

### 1. 创始人/CEO (1 人)

**薪资**: 股权 + 分红 (初期可不领薪)

**职责**:
- 制定公司战略和发展方向
- 融资和资金管理
- 核心资源整合 (银行、法院、中介)
- 团队建设和管理
- 重大决策和风险控制

**任职要求**:
- 有房地产行业经验 (优先)
- 有创业经验或管理能力
- 有本地人脉资源
- 对法拍房行业有深入了解

**招聘渠道**:
- 创始人自荐
- 合伙人招募

---

### 2. 业务经理 (2 人)

**薪资**: 15-20K + 提成 (总包 25-40K/月)

**职责**:
- 客户开发和业务拓展
- 维护客户关系
- 完成销售目标 (月均 10-15 单)
- 市场调研和竞品分析
- 协助制定营销策略

**任职要求**:
- 大专及以上学历
- 3 年以上房产销售经验
- 有法拍房/中介/银行信贷经验优先
- 熟悉宁波房地产市场
- 具备良好的沟通能力和抗压能力
- 有客户资源者优先

**面试流程**:
1. 简历筛选

3. 现场复试 (业务场景模拟)
4. 创始人终试
5. 背景调查

## 八、晋升通道

```

```


### 专业线晋升

```
初级 → 中级 → 高级 → 资深 → 专家 → 合伙人
```

### 晋升条件

| 晋升级别 | 工作年限 | 绩效要求 | 能力要求 |
|---------|---------|---------|---------|
| 初级→中级 | 1 年 | B+ 以上 | 独立完成工作 |
