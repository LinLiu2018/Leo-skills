# 乐橙荟商铺 · 抖音广告获客方案

> 目标：通过抖音信息流广告精准触达宁波及周边投资客群，获取有效线索
> 预算建议：首月测试期 5000-10000元/月，跑通模型后按效果加量
> 启动时间：3月初上线，配合3月7日项目全面启动

---

## 一、账户搭建

### 1.1 开户方式

- 平台：巨量引擎（oceanengine.com）
- 开户类型：房产/商业地产类
- 资质准备：营业执照、项目预售/销售许可、授权委托书
- 建议找当地抖音代理商开户，首充有返点（通常10-15%）

### 1.2 账户结构

```
广告账户
├── 计划1：信息流-表单收集（主力）
│   ├── 组1：宁波本地-25-55岁-投资理财兴趣
│   ├── 组2：宁波本地-别墅/高端住宅业主
│   └── 组3：浙江省-商铺投资关键词
├── 计划2：短视频引流-私信获客
│   ├── 组1：探店视频-宁波定向
│   └── 组2：算账视频-投资兴趣人群
└── 计划3：直播引流（可选）
    └── 组1：项目直播间引流
```

## 二、人群定向策略

### 2.1 核心定向（第一优先级）

| 维度 | 设置 |
|------|------|
| 地域 | 宁波市（重点鄞州、江东、东部新城）+ 周边慈溪、余姚、奉化 |
| 年龄 | 30-55岁 |
| 性别 | 不限（男性略偏多） |
| 兴趣标签 | 投资理财、房产投资、商铺、财经、银行理财、基金股票 |
| 行为标签 | 近30天搜索过"商铺投资""宁波房产""理财产品""被动收入" |
| 消费能力 | 中高消费 |

### 2.2 扩展定向（第二优先级）

| 维度 | 设置 |
|------|------|
| 地域 | 浙江省全省 |
| 人群包 | 别墅业主、高端车主、企业主、个体工商户 |
| 兴趣标签 | 创业、商业、财富管理、退休规划 |
| 排除 | 18-25岁、低消费人群 |

### 2.3 自定义人群包（进阶）

- 上传已有客户手机号做 lookalike 扩展
- 基于表单提交用户做相似人群扩展
- 排除已提交表单的用户避免重复触达

## 三、广告素材方案

### 3.1 信息流图片素材（3-5组）

**素材1：收益对比型**
- 画面：左右对比图，左边"银行定期2%"，右边"满租商铺6%"
- 标题：100万放银行4年赚8万，放这里4年赚22万
- 副标题：宁波鄞州·满租现铺·即买即收租

**素材2：品牌背书型**
- 画面：商场实景，突出星巴克/KFC/瑞幸门头
- 标题：星巴克肯德基给你交租｜宁波满租商铺在售
- 副标题：10年包租·前四年固定6-7%回报

**素材3：稀缺感型**
- 画面：商场鸟瞰/区位图
- 标题：鄞州核心区·3公里唯一商场·219套满租现铺
- 副标题：地铁5号线旁·15万人口消费圈

**素材4：安全感型**
- 画面：开发商自持示意图
- 标题：开发商自持2/3｜满租3年再卖铺｜不是空头承诺
- 副标题：一房一证·现房·3月可签约过户

### 3.2 信息流视频素材

直接使用前面制作的抖音脚本1（痛点切入）、脚本2（算账型）、脚本3（探店型）

### 3.3 素材制作要点

- 前3秒必须抓眼球：用数字、问题、痛点开头
- 画面要真实：用商场实拍，不要用效果图
- 字幕必须加：很多人静音刷抖音
- 时长控制：信息流15-30秒最佳
- 每周更新2-3组素材，避免素材疲劳

- 加信任元素：入驻品牌logo、商场实景图
- 加紧迫感："3月7日全面启动，提前预约享优先选铺"

## 五、投放策略

### 5.1 出价策略

| 阶段 | 出价方式 | 建议出价 | 日预算 |
|------|---------|---------|--------|
| 测试期（第1-2周） | OCPM-表单提交 | 80-120元/条线索 | 300-500元/天 |
| 优化期（第3-4周） | OCPM-表单提交 | 根据测试数据调整 | 500-800元/天 |
| 放量期（效果好时） | OCPM-表单提交 | 稳定出价 | 1000+元/天 |

### 5.2 投放时段

- 重点时段：11:00-13:00（午休）、19:00-23:00（晚间）
- 周末全天加量
- 避开凌晨0:00-7:00

### 5.3 优化节奏

| 时间 | 动作 |
|------|------|
| 每天 | 检查消耗、线索量、线索成本 |
| 每3天 | 关停效果差的素材/定向组，保留跑量好的 |
| 每周 | 更新2-3组新素材，测试新定向 |
| 每两周 | 复盘线索质量（到访率、成交率），反向优化定向 |

## 六、线索跟进流程

### 6.1 跟进时效

| 线索来源 | 跟进时效 | 跟进方式 |
|---------|---------|---------|
| 表单提交 | 5分钟内 | 电话回访 + 加微信 |
| 私信咨询 | 10分钟内 | 抖音私信回复 + 引导加微信 |
| 评论互动 | 1小时内 | 评论回复 + 私信跟进 |

### 6.2 电话回访话术

"您好，我是乐橙荟的[姓名]，看到您刚才在抖音上留了信息，想了解我们满租商铺的投资回报。我先加您微信，把项目实景和详细的收益测算发给您看，方便吗？"

### 6.3 微信跟进节奏

| 时间 | 动作 |
|------|------|
| 当天 | 发送项目资料包（实景图+收益测算+品牌清单） |
| 次日 | 跟进是否看了资料，解答疑问 |
| 第3天 | 邀约到访："周末方便来现场看看吗？满租的商场一看就有信心" |
| 第7天 | 未到访的再次邀约，结合商场活动 |
| 每周 | 朋友圈发商场动态、成交喜报，持续影响 |

## 七、预算与效果预估

### 7.1 首月测试预算

| 项目 | 费用 |
|------|------|
| 广告投放 | 8,000-15,000元 |
| 素材制作（拍摄+剪辑） | 2,000-3,000元 |
| 落地页制作 | 500-1,000元（用巨量引擎自带工具免费） |
| **合计** | **约10,000-18,000元** |

### 7.2 效果预估（保守）

| 指标 | 预估值 |
|------|--------|
| 线索成本 | 80-150元/条 |
| 月线索量 | 60-120条 |
| 有效率 | 40-60% |
| 到访率 | 15-25% |
| 月到访量 | 10-25组 |

### 7.3 ROI测算

- 假设月获客15组到访，成交率20%，月成交3套
- 单套均价120万，月销售额360万
- 广告投入1.5万，投入产出比 1:240
- 即使成交率只有10%，ROI依然非常可观
