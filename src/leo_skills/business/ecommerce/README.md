# 电商业务技能目录 (Business: Ecommerce)

本目录存放 AI 眼镜电商创业专用的 SKILL 模块，支持选品、文案和竞对分析。

## 规划技能清单

| 技能名称 | 目录名 | 说明 | 优先级 |
|---------|--------|------|-------|
| 爆款文案生成 | `viral_copywriting_skill` | 生成小红书/抖音风格的种草文案 | P0 |
| 竞品数据抓取 | `competitor_scraper_skill` | 抓取京东/淘宝/亚马逊的竞品销量和评价 | P0 |
| 选品分析报告 | `product_selection_skill` | 分析市场趋势，辅助选品决策 | P1 |
| 客户评论分析 | `review_analysis_skill` | 分析用户痛点和需求 | P2 |

## 开发规范

- 所有技能必须遵循 `snake_case_skill` 命名。
- 必须包含 `SKILL.md` 和 `scripts/main.py`。
