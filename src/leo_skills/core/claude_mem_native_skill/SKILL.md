# Claude Mem Native Skill

## 简介

`claude_mem_native_skill` - Claude-Mem原生集成

直接调用 `npx claude-mem` 命令，提供完整的跨会话记忆功能。

## 功能

- 查看记忆统计
- 搜索记忆
- 查看观察详情
- 管理记忆会话
- 与OpenClaw Gateway集成

## 使用方式

```
/claude-mem status          # 查看记忆状态
/claude-mem search <query>   # 搜索记忆
/claude-mem recent [limit]   # 最近记忆
/claude-mem stats           # 统计信息
```
