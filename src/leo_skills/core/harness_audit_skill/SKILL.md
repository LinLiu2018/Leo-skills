# Harness Audit Skill

## 简介

`harness_audit_skill` - Agent Harness性能审计工具

参考 ECC 的 `/harness-audit` 命令设计，为Leo AI系统提供全面的健康检查和性能诊断能力。

## 功能

- 系统配置检查
- Skill注册状态审计
- 记忆系统健康检查
- Hook执行状态监控
- 性能瓶颈识别
- 问题诊断与修复建议

## 使用方式

```
/harness-audit              # 执行完整审计
/harness-audit --quick      # 快速检查（不扫描文件）
/harness-audit --json       # JSON格式输出
/harness-audit --fix       # 自动修复可识别的问题
```
