# Daily News Summary Agent

**每日情报战略官** - 全球商业情报深度版，自动推送到飞书

## 快速激活

```
今日新闻摘要
生成全球商业情报
每日情报
定时推送
```

## 核心功能

### 1. 手动查询
- **AI动态**: 收集OpenAI/Anthropic/英伟达等最新动态
- **国际政治**: 中美关系、欧盟政策、两会动态
- **财经新闻**: 股市、加密货币、经济数据

### 2. 定时推送（飞书每日推送）
- **执行时间**: 每天早上 08:00 自动推送
- **推送方式**: 通过 OpenClaw 网关发送到飞书
- **内容格式**: 简洁版情报速递（适合手机阅读）

### 3. 深度报告（Obsidian同步）
- **位置**: `30-Resources/情报/`
- **内容**: 30条深度分析（AI+政治+财经各10条）
- **格式**: 摘要 + 商机/影响/信号

## 技能

- `web_search_skill`: 网络搜索最新新闻
- `research_assistant_skill`: 研究分析新闻内容
- `obsidian_sync_skill`: 同步到知识库

## 激活关键词

| 类别 | 关键词 |
|------|--------|
| 情报查询 | `新闻摘要`, `今日新闻`, `全球商业情报`, `每日情报` |
| 定时任务 | `定时推送`, `每日推送`, `开启定时` |
| 深度报告 | `深度情报`, `详细报告`, `完整版` |

## 使用示例

```\n# 手动查询（飞书即时回复）
今日新闻摘要
生成全球商业情报

# 深度报告（保存到Obsidian）
生成深度情报报告
详细版情报

# 定时推送
开启每日情报推送
```

## 定时任务配置

| 项目 | 值 |
|------|-----|
| 脚本 | `scripts/send_daily_intelligence.py` |
| 时间 | 每天 08:00 |
| 推送位置 | 飞书私聊 |
| 备份位置 | Obsidian `30-Resources/情报/` |

## 输出物

| 场景 | 输出 |
|------|------|
| **定时推送** | 飞书消息（简洁版） |
| **手动查询** | 飞书消息/深度报告 |
| **深度报告** | Obsidian 笔记 |
