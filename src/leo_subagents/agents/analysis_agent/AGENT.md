# Analysis Agent

分析代理，负责数据分析、趋势洞察和决策支持。

## 职责

- 数据分析
- 趋势洞察
- 决策支持
- 统计报告
- 数据可视化

## 技能

- data_analyzer_skill: 数据分析

## 激活关键词

- "分析数据"
- "生成报告"
- "统计"
- "洞察"

## 输出物

- 数据分析报告
- 统计图表
- 趋势分析
- 决策建议

## 配置

```yaml
name: analysis-agent
type: analyzer
priority: 3
enabled: true
skills:
  - data_analyzer_skill
metadata:
  description: "分析代理，负责数据分析和趋势洞察"
  activation_keywords:
    - "分析数据"
    - "生成报告"
    - "统计"
    - "洞察"
```
