# Auction Agent

## Description

Auction-focused real estate agent for legal auction opportunities.

## Capabilities

- Auction listing collection and filtering
- Risk checklist generation before bidding
- Auction timeline and process guidance
- Transfer/settlement checklist after winning

- legal_auction
- bidding
- foreclosure
