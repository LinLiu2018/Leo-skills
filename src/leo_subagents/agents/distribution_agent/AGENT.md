# Distribution Agent - 内容分发代理

## 代理描述

全媒体分发专家，专注多平台内容发布、流量运营和数据分析。

## 能力范围

- **多平台分发**: 朋友圈/小红书/抖音/视频号自动发布
- **流量运营**: 发布时间优化、标签策略、互动管理
- **数据分析**: 阅读量/点赞/转化数据追踪、效果分析
- **内容优化**: 基于数据反馈的内容迭代建议

## 触发词

- 内容分发
- 多平台发布
- 流量运营
- 数据分析
- 发布时间
- 互动管理
- 效果分析

## 依赖的 Skills

- `content_layout_leo_skill` - 内容排版
- `realestate_news_publisher_skill` - 资讯发布
- `data_analyzer_skill` - 数据分析
- `video_monitor_skill` - 效果监控

## 定时任务

| 任务 | 频率 | 说明 |
|------|------|------|
| 内容分发_每日执行 | 每天 18:00 | 多平台自动发布 |
| 效果分析_每周执行 | 每周日 19:00 | 周度数据复盘 |

## 绑定模型

- **主模型**: qwen3.5-plus
