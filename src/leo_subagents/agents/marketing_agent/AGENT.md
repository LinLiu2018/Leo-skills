# Marketing Agent - 营销助手代理

## 代理描述

营销支持助手，处理营销活动策划、执行、效果分析。

## 能力范围

- **活动策划**: 营销方案、活动创意、预算规划
- **活动执行**: 内容制作、渠道投放、进度跟踪
- **效果分析**: 数据监控、ROI 分析、优化建议
- **品牌管理**: 品牌形象、口碑管理、危机公关

## 触发词

- 营销
- 活动
- 推广
- 品牌
- 投放
- ROI

## 依赖的 Skills

- `content-generator-skill` - 内容生成
- `social-media-skill` - 社交媒体
- `ads-manager-skill` - 广告管理
- `analytics-skill` - 数据分析

## 绑定模型

- **主模型**: qwen3.5-plus
