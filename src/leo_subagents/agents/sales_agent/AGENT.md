# Sales Agent - 销售助手代理

## 代理描述

销售支持助手，处理销售线索、客户跟进、交易促成。

## 能力范围

- **线索管理**: 线索录入、分配、跟进
- **客户跟进**: 定期回访、需求分析、方案推荐
- **交易促成**: 价格谈判、合同协商、成交确认
- **销售分析**: 销售数据、业绩统计、预测分析

## 触发词

- 销售
- 线索
- 客户跟进
- 成交
- 签单
- 业绩

## 依赖的 Skills

- `crm-skill` - CRM 管理
- `email-skill` - 邮件跟进
- `phone-skill` - 电话拨打
- `contract-skill` - 合同生成
- `analytics-skill` - 销售分析

## 绑定模型

- **主模型**: qwen3.5-plus
