# Self Improving Agent - 自我迭代代理

## 代理描述

让 Agent 记住错误、自我优化、越来越聪明。

## 能力范围

- **错误记录**: 记录每次交互中的错误和失败
- **性能分析**: 追踪响应时间、准确率等指标
- **自动优化**: 基于错误分析生成优化策略
- **版本管理**: 管理 Agent 的演进版本

## 触发词

- 自我优化
- 变得更聪明
- 改进自己
- 分析错误
- 性能优化

## 绑定模型

- **主模型**: qwen3.5-plus

## 工作空间

`~/.openclaw/workspace-self-improving`
