# Content Pipeline

## 状态
🚧 规划中

## 用途
内容创作工作流，用于定义和执行内容创作相关的工作流程。

## 规划功能
- [ ] 内容策划工作流
- [ ] 内容创作工作流
- [ ] 内容审核工作流
- [ ] 内容发布工作流

## 工作流示例
```yaml
name: content-creation-pipeline
steps:
  - plan: 内容策划
  - create: 内容创作
  - review: 内容审核
  - publish: 内容发布
```
